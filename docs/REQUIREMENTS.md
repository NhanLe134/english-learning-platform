# Requirements

This is the initial application scaffold for the English Learning Platform.
The planned product includes learner and instructor workflows, courses and
lessons, ebooks, workshops, vocabulary practice, exercises, submissions,
grading, reports, and payments.

The technology stack is React, TypeScript, and Vite for the frontend; Node.js,
Express, and TypeScript for the REST API; Supabase for data and authentication;
Cloudinary for media; Resend for email; and a payment provider to be selected.

Product and business requirements should be confirmed before implementing
these workflows. The current API only provides a health endpoint.
