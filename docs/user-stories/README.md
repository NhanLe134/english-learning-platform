# Tài liệu User Story (User Stories)

Tài liệu này mô tả các chức năng và luồng nghiệp vụ của hệ thống English Learning Platform, được xây dựng dựa trên hành vi thực tế mà hệ thống hỗ trợ.

Tất cả User Story được viết bằng tiếng Việt, giữ nguyên thuật ngữ kỹ thuật cần thiết. Mỗi User Story mô tả nhu cầu người dùng, hành vi nghiệp vụ và kết quả mà hệ thống cần cung cấp, không mô tả cách hệ thống được triển khai kỹ thuật.
